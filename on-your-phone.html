On your phone

One tap to open, nothing to download, and about ninety seconds to set up

If you use this site more than occasionally, it is worth putting an icon on your home screen. It then sits with your other apps and opens with one tap — no address to type, and no scrolling back through old emails looking for the link.

It is not an App Store app. There is nothing to download, no account, no password and nothing to keep updated. The icon is a shortcut to the live site, and it takes up a few kilobytes. Apple now calls the result a web app; Android calls it an installed site; they are the same idea.

iPhone and iPad

Open this site in Safari. Tap the Share button — the square with an arrow coming out of the top. If you cannot see it, tap the … button to the right of the address first. Scroll down the list and tap Add to Home Screen. If you are offered a switch called Open as Web App, leave it on. Give it a name if you like, then tap Add.

Safari is the reliable route. Recent versions of Chrome on iPhone can do it too, from the same Share button, but Safari is the one that behaves the same way on every iPhone.

Android

Open the site in Chrome. Tap the three dots to the right of the address bar, and look for Install or Add to Home screen — Google has renamed this more than once, and recent versions put it under Install and create shortcut. Follow the prompt. Samsung Internet and Firefox have the same thing in their own menus.

Mac

In Safari, choose File then Add to Dock, and click Add. It lands in the Dock and in Spotlight, like any other application. In Chrome, use the ⋮ menu, then Cast, save and share, then Install page as app.

Windows

In Edge, use the … menu, then More tools, then Apps, then Install this site as an app. In Chrome, the ⋮ menu, then Cast, save and share, then Install page as app.

  • It is not offline. The icon opens the live site, so in a lift or a basement corridor it will not load, exactly as the browser would not. This is a deliberate choice rather than an oversight.
  • You always get the current version. That is the other side of the same coin — there is no stored copy on your phone to go stale, and nothing to update.
  • Nothing to sign up for. No App Store, no Apple ID, no Google account, no password. Nothing is installed in the sense that an app is installed.
  • It opens the front page. Whichever page you are reading when you add it, the icon takes you to the landing page, and everything is a tap or two from there.
  • If the wording on your screen does not match the above, look for the word Share, Install or Add and you will find it. Apple and Google both rename these menus from time to time. If you get stuck, tell me what you see and I will work it out and fix this page.

If you would rather not do any of this, nothing is lost. Everything on the site works perfectly well from a browser, a bookmark or the link in the newsletter.
